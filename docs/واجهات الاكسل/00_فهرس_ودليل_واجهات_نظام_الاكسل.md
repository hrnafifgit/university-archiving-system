# دليل وفهرس واجهات نظام الأرشفة السابق (Excel / VBA)
### ملف النظام: `ibbunvAkademy.xlsm` (جامعة إب - الشؤون الأكاديمية)

يوثق هذا الدليل التحليل الفني المعمق لكافة **الواجهات والنماذج البرمجية (UserForms)** و**شاشات أوراق العمل (Worksheet Interfaces)** المستخرجة مباشرة من الكود البرمجي لماكرو الإكسل في ملف `ibbunvAkademy.xlsm`.

---

## 📑 خريطة واجهات النظام في الإكسل

يتكون نظام الإكسل السابق من منظومة واجهات متكاملة مبرمجة بلغة **VBA (Visual Basic for Applications)** تعمل بالتكامل مع **16 ورقة عمل (Worksheets)**:

```
                            [ شاشة البداية star2 ]
                                      │
                                      ▼
                        [ UserForm0: واجهة تسجيل الدخول ] (رمز السري: 123)
                                      │
                                      ▼
                   [ MenuForm: شاشة التحكم الرئيسية والعمليات ]
                                      │
      ┌──────────────────┬────────────┴─────────────┬──────────────────┐
      ▼                  ▼                          ▼                  ▼
[ UFormChang ]      [ bisho ]               [ ReportForm ]       [ eh1 - eh8 ]
واجهة إدخال وتعديل   واجهة البحث والتصفية   واجهة التقارير       شاشات الإحصائيات
الكادر وعارض PDF     والإحصاء السريع        والطباعة             الثمانية المتخصصة
 (D:\archac26\)     (8 ComboBoxes)          (شيت prnn)           (كليات ورتب)
```
