# نظام الأرشفة الجامعي الإلكتروني — جامعة إب
### University Archiving System (UAS) - Ibb University 🇾🇪

مشروع التخرج الأكاديمي لطلاب المستوى الرابع — كلية الهندسة وتكنولوجيا المعلومات — جامعة إب.
منظومة ويب متكاملة مبنية بإطار عمل **Laravel** وقاعدة بيانات علائقية مطبقة لمعايير **3NF**، تهدف إلى رقمنة وأرشفة وثائق كادر الجامعة الأكاديمي والإداري والمتعاقدين بالساعات، والتحول الكامل من نظام الماكرو المكتبي القديم (`ibbunvAkademy.xlsm`).

---

## 🏛️ مميزات النظام
- **الهوية البصرية لجامعة إب:** واجهات مصممة بالكامل وفق الهوية المؤسسية للجامعة مع الشعار الرسمي والألوان الأكاديمية (RTL).
- **معمارية بيانات 3NF:** تطبيع كامل لسجلات الكادر عبر نمط التوريث (Polymorphic Subtypes: كادر أكاديمي، كادر إداري، متعاقد بالساعات).
- **معالج إدخال ذكي أفقي (Step Wizard):** 4 خطوات تفاعلية بدون تمرير (Zero Scroll).
- **قوائم منسدلة مطابقة للواقع:** 18 كلية ومركزاً، 69 قسماً ووحدة علمية وإدارية، 16 حالة وظيفية، و 6 رتب أكاديمية مستخرجة من سجلات الجامعة الرسمية.
- **عارض PDF مدمج وشجرة أرشيف رقمية:** استعراض مباشر لكافة الوثائق والقرارات الصادرة مع تشفير مسارات التخزين بهوية UUID فريدة.
- **محرك بحث وتصفية متقدم:** مطابق لآلية واجهة الاستعلام السابقة `bisho` مع عدادات إحصائية رقمية فورية.
- **مركز التقارير وبيان الحالة:** استخراج وطباعة بيان الحالة الوظيفية والأكاديمية المعتمد بالعلامة المائية الرسمية للجامعة.

## 📂 هيكلية المشروع
```text
├── uas_backend/            # منصة الويب المتكاملة (Laravel 12.x Backend & Blade Views)
│   ├── app/Models/         # النماذج العلائقية (StaffBase, AcademicDetail, DigitalArchive...)
│   ├── app/Http/Controllers/ # المتحكمات (StaffController, DashboardController)
│   ├── database/migrations/ # هجرات الجداول الـ 12 وفق مخطط 3NF
│   ├── database/seeders/   # التغذية المرجعية للكليات والأقسام والرتب
│   ├── resources/views/    # شاشات العرض التفاعلية (Blade + Tailwind CSS)
│   └── public/images/      # شعارات وهوية جامعة إب الرسمية
├── ui_mockups/             # النماذج البصرية والتصاميم الأولية للواجهات
├── واجهات الاكسل/          # التوثيق والتحليل الهندسي لكافة ماكروهات ونماذج الإكسل السابق
├── المخطط الجديد.drawio     # مخطط الكينونات والعلاقات العلائقي (ERD 3NF)
└── agent.md                # سجل المتابعة والقرارات الهندسية المنفذة
```

## 🚀 متطلبات وتشغيل النظام محلياً

```bash
# 1. الدخول لمجلد الموقع
cd uas_backend

# 2. تثبيت الحزم (إن لم تكن مثبتة)
composer install

# 3. نسخ ملف البيئة وتوليد المفتاح
cp .env.example .env
php artisan key:generate

# 4. تشغيل الهجرات والتغذية المرجعية
php artisan migrate --seed

# 5. ربط مجلد التخزين العام للأرشيف
php artisan storage:link

# 6. تشغيل السيرفر المحلي
php artisan serve
```

ثم الدخول عبر المتصفح إلى: `http://127.0.0.1:8000`
