## 📌 عن المشروع (About The Project)

**نظام الأرشفة الجامعي** هو مشروع تخرج يُعنى بالتحول الرقمي لأرشفة وإدارة بيانات ووثائق منتسبي الجامعة (أعضاء هيئة التدريس، الكادر الإداري، والمتعاقدين). يهدف النظام إلى معالجة قصور الأنظمة المكتبية السابقة عبر بناء منظومة مركزية تؤرشف الملفات الإلكترونية والقرارات والمستندات الرسمية، وتربطها بملف وظيفي وأكاديمي موحد وهيكل تنظيمي هرمي دقيق.

## 🔄 دوافع التحول والتطوير (As-Is vs To-Be)

| معيار المقارنة | الوضع المكتبي السابق (Excel / VBA Desktop) | نظام الأرشفة الجامعي الحديث (Modern Web Platform) |
| :--- | :--- | :--- |
| **طبيعة الأرشفة** | حفظ محلي بمسارات ثابتة (`D:\archac26\`) معرضة للفقد والتلف | أرشفة رقمية سحابية مؤمنة وفهرسة مستندية مع عارض تفاعلي لوثائق PDF |
| **هندسة النظام** | ملف محلي على جهاز واحد بدون قابلية للربط الشبكي | بنية العميل/الخادم (RESTful API / Web Architecture) قابلة للوصول المركزي |
| **قاعدة البيانات** | جداول مسطحة ممتدة (44 حقلاً) تفتقر للتطبيع | قاعدة بيانات علائقية معيارية محكمة خالية من التكرار (3NF Relational DB) |
| **تعدد المستخدمين** | مستخدم واحد فقط مع خطر تعارض وتلف البيانات | تزامن وتعدد وصول (Multi-User) مع إدارة حركات وقفل السجلات (ACID) |
| **الأمان وحماية الوثائق** | كلمة مرور وحيدة وسطحية للجميع | نظام صلاحيات دقيق قائم على الأدوار (Role-Based Access Control - RBAC) |
| **البحث والاسترجاع** | بحث يدوي بطيء ومحدود | محرك بحث وفلترة متقدم بالرقم الوظيفي، الاسم، الكلية، ونوع الوثيقة |

## 🧩 الركائز الأساسية للنظام (Core Modules)

1. **إدارة الأرشيف الرقمي والوثائق (Digital Archiving & Document Management):**
   - أرشفة الشهادات، المؤهلات، قرارات التعيين، الترقيات، الإيفاد، والتفرغ العلمي.
   - شجرة وثائق تفاعلية لكل كادر تتيح معاينة وتحميل ملفات الـ PDF بسرعة وأمان.
   - ربط آلي بين اسم الملف الإلكتروني والرمز التعريفي للموظف لمنع التداخل.

2. **ملف الكادر الموحد (Unified Staff Profiles):**
   - سجل موحد للبيانات الشخصية والأساسية يمنع الازدواجية والتكرار.
   - تصنيف مرن يشمل:
     - أعضاء هيئة التدريس ومساعديهم (معيد، مدرس، أستاذ مساعد، أستاذ مشارك، أستاذ دكتور).
     - الكادر الإداري والعاملين (الدرجات الوظيفية والمجموعات النوعية).
     - كادر الساعات والتعاقدات.
   - مطابقة بيانات الكادر مع كشوفات الرواتب الرسمية والقرارات الإدارية.

3. **الهيكل التنظيمي الهرمي (Organizational Hierarchy):**
   - هيكل مرن للجهات الإدارية والأكاديمية (كليات، مراكز، عمادات، دوائر).
   - تقسيمات فرعية للمستويات التابعة (أقسام علمية، وحدات إدارية، مكاتب).

4. **لوحة التحكم والتقارير والتدقيق (Control Panel & Audit Trail):**
   - لوحة قيادة تفاعلية بمؤشرات لحظية وإحصائيات تقاطعية لأصحاب القرار.
   - سجل تدقيق إداري (Audit Logs) لتوثيق كل حركة إضافة أو تعديل أو استعراض لوثيقة.

## 🛠️ التقنيات المقترحة (Proposed Tech Stack)

- **Backend:** Node.js (Express / NestJS) أو Python (FastAPI) أو Laravel
- **Frontend:** React.js / Next.js بتصميم حديث، أنيق، وسريع الاستجابة (RTL)
- **Database:** PostgreSQL / MySQL مصممة وفق معايير 3NF
- **Document Storage:** Secure Storage Service للملفات والمستندات الرقمية
- **Security:** JWT Authentication & RBAC
