## 📌 نبذة عامة عن المشروع (Overview)

يُعد الكادر الأكاديمي والإداري العمود الفقري للعملية التعليمية والإدارية في جامعة إب. يهدف هذا المشروع إلى بناء **منصة ويب سحابية مركزية وموحدة** لأرشفة وإدارة المسار الأكاديمي، الوظيفي، والمالي لمنتسبي الجامعة من تاريخ التعيين وحتى نهاية الخدمة، مع ربط المستندات والوثائق بـ **أرشيف رقمي ذكي** وتجاوز محدوديات النظام المكتبي السابق.

## 🔄 دراسة الفجوة والتحول (As-Is vs To-Be)

| معيار المقارنة | الوضع المكتبي القديم (Excel / VBA) | منصة الويب الحديثة المقترحة (To-Be) |
| :--- | :--- | :--- |
| **هندسة النظام** | ملف محلي على جهاز واحد (Single Desktop File) | منصة ويب سحابية متعددة المستخدمين (Client-Server / RESTful API) |
| **قاعدة البيانات** | جدول مسطح ممتد (44 عموداً في شيت إكسل) بدون تطبيع | قاعدة بيانات علائقية معيارية محكمة (3NF Relational DB) |
| **تعدد المستخدمين** | مستخدم واحد فقط في نفس اللحظة مع خطر الكتابة المتزامنة | دعم التزامن الكامل (Concurrency & ACID Transactions) |
| **الأرشيف الرقمي** | مسار محلي صلب (`D:\archac26\`) يعتمد على المتصفح المدمج | نظام أرشفة وتخزين مؤمن للوثائق بصيغة PDF مع عارض تفاعلي |
| **الأمان والصلاحيات** | كلمة مرور وحيدة وثابتة (123) بدون أي صلاحيات | نظام إدارة وصول قائم على الأدوار (Role-Based Access Control - RBAC) |
| **التقارير والإحصائيات** | فلاتر ومعادلات إكسل يدوية عرضة للتلف | لوحة مؤشرات قيادة تفاعلية (Dashboard) وإحصائيات تقاطعية لحظية |

## 🧩 الهيكلية ومحاور النظام الأساسية (Key Modules)

1. **إدارة الهيكل التنظيمي الهرمي (Organizational Hierarchy):**
   - تمثيل ديناميكي متعدد المستويات للجهات (كليات، مراكز، عمادات، دوائر).
   - تقسيمات فرعية مرنة (أقسام علمية، وحدات إدارية، شعب).

2. **ملف الكادر الموحد (Staff Profile Management):**
   - **البيانات الشخصية والأساسية:** سجل مركزي وموحد يمنع التكرار.
   - **تصنيف الكوادر:**
     - أعضاء هيئة التدريس ومساعديهم (معيد، مدرس، أستاذ مساعد، أستاذ مشارك، أستاذ دكتور).
     - الكادر الإداري والعاملين (الدرجات الوظيفية، المجموعات النوعية).
     - كادر التعاقد والساعات.
   - **المسار الأكاديمي والتدرج العلمي:** الدرجات العلمية (بكالوريوس، ماجستير، دكتوراه)، جهة التخرج، التخصص الدقيق، أطروحات التخرج.
   - **القرارات الإدارية والمالية:** قرارات التعيين، التثبيت، الترقيات، التفرغ العلمي، الإيفاد والابتعاث، ومطابقة كشوفات الرواتب.

3. **منظومة الأرشيف الرقمي للمستندات (Electronic Document Archiving):**
   - شجرة وثائق رقمية مرتبطة بكل موظف (شهادات، قرارات، هويات، مؤهلات).
   - فهرسة مستندية دقيقة تمنع الفقد والتلف، وتدعم المعاينة الفورية لملفات الـ PDF.

4. **الأمان والتدقيق (Security & Audit Trail):**
   - تسجيل عمليات النظام (Audit Logs) لمعرفة من قام بالإضافة أو التعديل وتوقيته.
   - صلاحيات دقيقة بحسب الكلية، المركز، أو الإدارة العامة للشؤون الأكاديمية.

## 🛠️ التقنيات المقترحة (Proposed Tech Stack)

- **Backend:** Node.js (Express / NestJS) أو Python (FastAPI / Django) أو Laravel / .NET
- **Frontend:** React.js / Next.js أو Vue.js مع واجهة مستخدم عصرية وسريعة الاستجابة (RTL)
- **Database:** PostgreSQL أو MySQL بتصميم علائقي 3NF
- **Storage:** Secure Storage Engine لملفات الـ PDF والأرشيف الرقمي
- **Authentication:** JWT & Role-Based Access Control (RBAC)
