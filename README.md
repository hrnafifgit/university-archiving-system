# نظام الأرشفة الجامعي الإلكتروني — جامعة إب
### University Archiving System (UAS v2.0) - Ibb University 🇾🇪

منظومة ويب متكاملة ومطورة لإدارة وتوثيق ملفات وسجلات كادر الجامعة الأكاديمي والإداري والمتعاقدين بالساعات مع الأرشفة الرقمية والتحقق الأمني.

---

## 🏛️ البنية المنظمة للمشروع (Project Structure)

تم تنظيم المشروع ليكون واضحاً ومرتباً تماماً:

```text
university-archiving-system/
│
├── 📂 uas_backend/          # المنصة البرمجية والموقع الفعلي بالكامل (Laravel 12 + PostgreSQL 18)
│   ├── app/                # النماذج (Models)، المتحكمات (Controllers)
│   ├── database/           # هجرات الـ 42 جدولاً وقواعد البيانات، والتغذية المرجعية (Seeders)
│   ├── resources/views/    # شاشات الموقع وواجهات العرض (Blade + Tailwind CSS RTL)
│   ├── routes/web.php      # مسارات النظام والروابط
│   └── storage/            # التخزين المحمي لوثائق الأرشيف (PDF)
│
├── 📂 docs/                 # مستندات التوثيق والتحليل والمخططات الأكاديمية
│   ├── ai/                 # وثائق التحليل والمخططات المعمارية ومستندات Word
│   ├── ui_mockups/         # نماذج وتصاميم واجهات المستخدم المقترحة
│   ├── واجهات الاكسل/      # تحليل وتفريغ نماذج وماكرو نظام الإكسل السابق
│   └── المخطط الجديد.drawio# المخطط المعماري الكامل لقاعدة البيانات
│
├── 📄 agent.md             # سجل طلبات المشروع والإجراءات الهندسية المنفذة
└── 📄 README.md            # هذا الملف التعريفي المنظم
```

---

## 🚀 تشغيل المنصة محلياً

```bash
# 1. الدخول لمجلد الموقع البرمجي
cd uas_backend

# 2. تشغيل السيرفر المحلي
php artisan serve
```

ثم فتح المتصفح على: **`http://127.0.0.1:8000`**
